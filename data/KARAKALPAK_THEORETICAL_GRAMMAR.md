# 📚 QARAQALPAQ TILINIŃ TEORIYALÍQ GRAMMATIKASÍ (Qudaybergenov, 2017)
### Academic Linguistic Reference & Rules for AI Translation

This document synthesizes the core rules from the university textbook:
**"Qaraqalpaq tiliniń teoriyalıq grammatikası" (Nókis, 2017)** by M. Qudaybergenov, A. Qazaqbaeva, A. Kurtchaev.

---

## 1. Singarmonizm (Vowel Harmony)

Karakalpak strictly observes phonological vowel harmony:
* **Juwan dawıslılar (Back / Hard vowels)**: `a`, `ı`, `o`, `u`
  - Suffixes attached to back-vowel roots MUST take back vowels:
    - Plural: `-lar`
    - Dative (Barıs): `-ǵa / -qa`
    - Locative (Orın): `-da / -ta`
    - Ablative (Shıǵıs): `-dan / -tan / -nan`
    - Personal 1st person: `-man / -pan / -ban`
* **Jińishke dawıslılar (Front / Soft vowels)**: `e`, `i`, `ó`, `ú`, `á`
  - Suffixes attached to front-vowel roots MUST take front vowels:
    - Plural: `-ler`
    - Dative (Barıs): `-ge / -ke`
    - Locative (Orın): `-de / -te`
    - Ablative (Shıǵıs): `-den / -ten / -nen`
    - Personal 1st person: `-men / -pen / -ben`

> **Rule for Loanwords**:
> Words ending in front vowels (e.g., *intellekt*, *universitet*, *prezident*) ALWAYS take front-vowel endings:
> - `intellekt` + 1st person -> **`intellektpen`** (NEVER *intellektpin*).
> - `prezident` + 1st person -> **`prezidentpen`**.

## 2. Betlik Jalǵawları (Personal / Predicative Suffixes)

Attached to nouns, adjectives, and verbs acting as predicates:

| Person | Pronoun | After Vowels & Sonorants (l, m, n, ń, r, w, y) | After Voiceless (p, t, k, q, s, sh, ch, x, f) | After Voiced (b, d, g, ǵ, z, j) |
|---|---|---|---|---|
| **I (Singular)** | *Men* | `-man / -men` (*oqıwshıman, muǵallimmen*) | `-pan / -pen` (*jaspan, intellektpen, studentpen*) | `-ban / -ben` (*jazıwshıban*) |
| **I (Plural)** | *Biz / Bizler* | `-mız / -miz` (*oqıwshımız*) | `-pız / -piz` (*studentpiz*) | `-bız / -biz` (*adamlarbız*) |
| **II (Singular)** | *Sen* | `-sań / -seń` (*sen oqıwshısań, sen studentsıń*) | `-sań / -seń` | `-sań / -seń` |
| **II (Polite/Plural)**| *Siz / Sizler* | `-sız / -siz` (*siz oqıwshısız*) | `-sız / -siz` | `-sız / -siz` |
| **III** | *Ol / Olar* | Zero (`-`) or `-dı / -di` | Zero (`-`) or `-tı / -ti` | Zero (`-`) or `-dı / -di` |

## 3. Seplik Jalǵawları (Noun Cases)

| Seplik (Case) | Meaning | Back Vowel Suffix | Front Vowel Suffix | Example |
|---|---|---|---|---|
| **Ataw (Nominative)** | Subject / Base | `-` | `-` | *kitap, mektep* |
| **Iyelik (Genitive)** | Possession / of | `-nıń / -dıń / -tıń` | `-niń / -diń / -tiń` | *kitaptıń, eldiń, balanıń* |
| **Barıs (Dative)** | Direction / to, for | `-ǵa / -qa / -na` | `-ge / -ke / -ne` | *awılǵa, mektepke, úyine* |
| **Tabıs (Accusative)** | Direct Object | `-nı / -dı / -tı / -n` | `-ni / -di / -ti / -n` | *kitaptı, qálemdi, qalanı* |
| **Orın (Locative)** | Location / in, at, on | `-da / -ta / -nda` | `-de / -te / -nde` | *qalada, mektepte, qolında* |
| **Shıǵıs (Ablative)** | Origin / from, than | `-dan / -tan / -nan` | `-den / -ten / -nen` | *awıldan, mektepten, úyinen* |

## 4. Feyil Meyilleri hám Zamandarı (Verb Moods & Tenses)

1. **Anıq házirgi máhál (Present Continuous)**:
   - Formed using analytical forms: `-p / -a / -e` + `otır`, `tur`, `júr`, `jatır`, `atır`.
   - Examples: `jazıp atır`, `oqıp otır`, `kórip tur`, `islep júr`.
2. **Keler máhál (Future)**:
   - Categorical: `-jaq / -jek` (`barajaqpan`, `jazajaq`).
   - Intention: `-maqshı / -mekshi` (`barmaqshıman`).
   - Assumptive: `-ar / -er` (`keler`, `barar`).
3. **Ótken máhál (Past)**:
   - Witnessed past: `-dı / -di`, `-tı / -ti` (`keldi`, `kórdi`, `jazdı`).
   - Narrative past: `-ǵan / -gen`, `-qan / -ken` (`kelgen`, `aytqan`).
4. **Bolımsız feyil (Negation)**:
   - Suffixes: `-ma / -me`, `-ba / -be`, `-pa / -pe` (`jazba`, `kórme`, `aytpa`).

## 5. Kelbetlik Dárejeleri (Adjective Intensification)

* **Jartılay reduplikaciya (Intensive prefix-like syllable)**:
  - `qara` -> **`qap-qara`**
  - `qızıl` -> **`qıp-qızıl`**
  - `sarı` -> **`sap-sarı`**
  - `úlken` -> **`úp-úlken`**
  - `ashshı` -> **`ap-ashshı`**
  - `tik` -> **`tip-tik`**
* **Analitikalıq dáreje**:
  - `júdá`, `dım`, `oǵırı`, `orasan` (e.g. *júdá qızıq*, *dım qara*).

---

## 6. Qospa Sózler (Compound Words)

* **Birikken sózler (Written together)**:
  - *asqazan*, *tasbaqa*, *aqquw*, *kókjótel*, *qoljazba*, *kúnshıǵıs*, *búgin*, *bıyıl*.
* **Jup sózler (Hyphenated)**:
  - *áke-sheshe*, *ata-ana*, *awıl-aymaq*, *dos-dushpan*, *azlı-kópli*, *kún-tún*.
* **Tákirar sózler (Reduplicated)**:
  - *kóre-kóre*, *úyme-úy*, *qora-qora*, *sóyley-sóyley*.

---

## 7. Sintaksis (Sentence Structure)

* **Turkic SOV word order**:
  `Baslawısh (Subject)` + `Anıqlawısh / Tolıqlawısh / Pısıqlawısh (Objects / Adverbials)` + `Bayanlawısh (Verb / Predicate)`.
* **Adjective-Noun agreement**:
  Adjectives preceding nouns DO NOT take plural or case endings:
  - `biyik tawlar` (CORRECT)
  - ~~`biyikler tawlar`~~ (INCORRECT)

### C. 2016-jılǵı Rásmiy Qaraqalpaq Latın Alfavitiniń Ózgeshelikleri:
1. **Akutlı háripler**: `Á á`, `Ǵ ǵ`, `Ń ń`, `Ó ó`, `Ú ú`.
2. **Nókatsız `ı`**: Juwan dawıslı (uzınlıq, shıǵıs, qız).
3. **Nókatlı `i`**: Jińishke dawıslı (bir, tis, minnetleme). 'mínnetleme' jazıw qáte, 'minnetleme' jazılıwı shárt.
4. **Toponimler hám atamalar**:
   - `Uzgidromet` ➔ **`Ózgidromet`**
   - `Savitskiy` ➔ **`Savickiy`**
   - `Alat` ➔ **`Álot`**
