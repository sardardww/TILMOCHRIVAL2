# 📚 QARAQALPAQ TILINIŃ TEORIYALÍQ GRAMMATIKASÍ (Qudaybergenov, 2017)
### Academic Linguistic Reference & Rules for AI Translation

This document synthesizes the core rules from the university textbook:
**"Qaraqalpaq tiliniń teoriyalıq grammatikası" (Nókis, 2017)** by M. Qudaybergenov, A. Qazaqbaeva, A. Kurtchaev.

---

## 1. Singarmonizm (Vowel Harmony)

Karakalpak strictly observes phonological vowel harmony:
* **Juwan dawıslılar (Back / Hard vowels)**: `a`, `ı`, `o`, `u`
  - Suffixes attached to back-vowel roots MUST take back vowels:
    - Plural: `-lar`
    - Dative (Barıs): `-ǵa / -qa`
    - Locative (Orın): `-da / -ta`
    - Ablative (Shıǵıs): `-dan / -tan / -nan`
    - Personal 1st person: `-man / -pan / -ban`
* **Jińishke dawıslılar (Front / Soft vowels)**: `e`, `i`, `ó`, `ú`, `á`
  - Suffixes attached to front-vowel roots MUST take front vowels:
    - Plural: `-ler`
    - Dative (Barıs): `-ge / -ke`
    - Locative (Orın): `-de / -te`
    - Ablative (Shıǵıs): `-den / -ten / -nen`
    - Personal 1st person: `-men / -pen / -ben`

> **Rule for Loanwords**:
> Words ending in front vowels (e.g., *intellekt*, *universitet*, *prezident*) ALWAYS take front-vowel endings:
> - `intellekt` + 1st person -> **`intellektpen`** (NEVER *intellektpin*).
> - `prezident` + 1st person -> **`prezidentpen`**.

## 2. Betlik Jalǵawları (Personal / Predicative Suffixes)

Attached to nouns, adjectives, and verbs acting as predicates:

| Person | Pronoun | After Vowels & Sonorants (l, m, n, ń, r, w, y) | After Voiceless (p, t, k, q, s, sh, ch, x, f) | After Voiced (b, d, g, ǵ, z, j) |
|---|---|---|---|---|
| **I (Singular)** | *Men* | `-man / -men` (*oqıwshıman, muǵallimmen*) | `-pan / -pen` (*jaspan, intellektpen, studentpen*) | `-ban / -ben` (*jazıwshıban*) |
| **I (Plural)** | *Biz / Bizler* | `-mız / -miz` (*oqıwshımız*) | `-pız / -piz` (*studentpiz*) | `-bız / -biz` (*adamlarbız*) |
| **II (Singular)** | *Sen* | `-sań / -seń` (*sen oqıwshısań, sen studentsıń*) | `-sań / -seń` | `-sań / -seń` |
| **II (Polite/Plural)**| *Siz / Sizler* | `-sız / -siz` (*siz oqıwshısız*) | `-sız / -siz` | `-sız / -siz` |
| **III** | *Ol / Olar* | Zero (`-`) or `-dı / -di` | Zero (`-`) or `-tı / -ti` | Zero (`-`) or `-dı / -di` |

## 3. Seplik Jalǵawları (Noun Cases)

| Seplik (Case) | Meaning | Back Vowel Suffix | Front Vowel Suffix | Example |
|---|---|---|---|---|
| **Ataw (Nominative)** | Subject / Base | `-` | `-` | *kitap, mektep* |
| **Iyelik (Genitive)** | Possession / of | `-nıń / -dıń / -tıń` | `-niń / -diń / -tiń` | *kitaptıń, eldiń, balanıń* |
| **Barıs (Dative)** | Direction / to, for | `-ǵa / -qa / -na` | `-ge / -ke / -ne` | *awılǵa, mektepke, úyine* |
| **Tabıs (Accusative)** | Direct Object | `-nı / -dı / -tı / -n` | `-ni / -di / -ti / -n` | *kitaptı, qálemdi, qalanı* |
| **Orın (Locative)** | Location / in, at, on | `-da / -ta / -nda` | `-de / -te / -nde` | *qalada, mektepte, qolında* |
| **Shıǵıs (Ablative)** | Origin / from, than | `-dan / -tan / -nan` | `-den / -ten / -nen` | *awıldan, mektepten, úyinen* |

## 4. Feyil Meyilleri hám Zamandarı (Verb Moods & Tenses)

1. **Anıq házirgi máhál (Present Continuous)**:
   - Formed using analytical forms: `-p / -a / -e` + `otır`, `tur`, `júr`, `jatır`, `atır`.
   - Examples: `jazıp atır`, `oqıp otır`, `kórip tur`, `islep júr`.
2. **Keler máhál (Future)**:
   - Categorical: `-jaq / -jek` (`barajaqpan`, `jazajaq`).
   - Intention: `-maqshı / -mekshi` (`barmaqshıman`).
   - Assumptive: `-ar / -er` (`keler`, `barar`).
3. **Ótken máhál (Past)**:
   - Witnessed past: `-dı / -di`, `-tı / -ti` (`keldi`, `kórdi`, `jazdı`).
   - Narrative past: `-ǵan / -gen`, `-qan / -ken` (`kelgen`, `aytqan`).
4. **Bolımsız feyil (Negation)**:
   - Suffixes: `-ma / -me`, `-ba / -be`, `-pa / -pe` (`jazba`, `kórme`, `aytpa`).

## 5. Kelbetlik Dárejeleri (Adjective Intensification)

* **Jartılay reduplikaciya (Intensive prefix-like syllable)**:
  - `qara` -> **`qap-qara`**
  - `qızıl` -> **`qıp-qızıl`**
  - `sarı` -> **`sap-sarı`**
  - `úlken` -> **`úp-úlken`**
  - `ashshı` -> **`ap-ashshı`**
  - `tik` -> **`tip-tik`**
* **Analitikalıq dáreje**:
  - `júdá`, `dım`, `oǵırı`, `orasan` (e.g. *júdá qızıq*, *dım qara*).

## 6. Qospa Sózler (Compound Words)

* **Birikken sózler (Written together)**:
  - *asqazan*, *tasbaqa*, *aqquw*, *kókjótel*, *qoljazba*, *kúnshıǵıs*, *búgin*, *bıyıl*.
* **Jup sózler (Hyphenated)**:
  - *áke-sheshe*, *ata-ana*, *awıl-aymaq*, *dos-dushpan*, *azlı-kópli*, *kún-tún*.
* **Tákirar sózler (Reduplicated)**:
  - *kóre-kóre*, *úyme-úy*, *qora-qora*, *sóyley-sóyley*.

---

## 7. Sintaksis (Sentence Structure)

* **Turkic SOV word order**:
  `Baslawısh (Subject)` + `Anıqlawısh / Tolıqlawısh / Pısıqlawısh (Objects / Adverbials)` + `Bayanlawısh (Verb / Predicate)`.
* **Adjective-Noun agreement**:
  Adjectives preceding nouns DO NOT take plural or case endings:
  - `biyik tawlar` (CORRECT)
  - ~~`biyikler tawlar`~~ (INCORRECT)

### C. 2016-jılǵı Rásmiy Qaraqalpaq Latın Alfavitiniń Ózgeshelikleri:
1. **Akutlı háripler**: `Á á`, `Ǵ ǵ`, `Ń ń`, `Ó ó`, `Ú ú`.
2. **Nókatsız `ı`**: Juwan dawıslı (uzınlıq, shıǵıs, qız).
3. **Nókatlı `i`**: Jińishke dawıslı (bir, tis, minnetleme). 'mínnetleme' jazıw qáte, 'minnetleme' jazılıwı shárt.
4. **Toponimler hám atamalar**:
   - `Uzgidromet` ➔ **`Ózgidromet`**

   - `Alat` ➔ **`Álot`**

### D. Tabıs Sepligi Assimilyaciyası (Accusative Case Assimilation):

| *ilimti* | **ilimdi** | Únli 'm' dawıssızınan keyin '-di' qosıladı |

### E. Leksikalıq hám Semantikalıq Qáteliklerdiń Kelip Shıǵıw Sebepleri (Linguistic Root-Cause Analysis)

Mashinalıq awdarma hám neyrotarqaǵıshlar (LLM) qaraqalpaq tiline awdarma jasaǵanda eń kóp jol qoyatuǵın sistemalı qáteliklerdiń lingvistikalıq sebepleri hám dálilleri:

1. **2016-jılǵı Latın Orfografiyasınıń 'c' háribi (Xalıqaralıq sózler)**:
   - **Qátelik**: *aksiyalar, aksiyalardıń, konstitutsiya, politsiya*
   - **Durıs**: **`akciyalar`**, **`akciyalardıń`**, **`konstituciya`**, **`policiya`**
   - **Kelip shıǵıw sebebi**: Ózbek latın imlosında `s` yamasa `ts` qollanıladı (*aksiya, konstitutsiya*). Qaraqalpaq tiliniń 2016-jılǵı rásmiy latın alfavitinde bolsa rus tilindegi «ц» háribi xalıqaralıq sózlerde qatań túrde **`c`** háribi arqalı tańbalanadı. Neyrotarmoqlar ózbek tili korpusınıń tásirinde `ks` dep jazıp qoyadı.

2. **Semantikalıq Psevdo-Kalka (Data Center ➔ Derek-orayı qáteligi)**:
   - **Qátelik**: *derek-orayları, derek-oraylarında*
   - **Durıs**: **`maǵlıwmatlar orayı`** (yamasa *data-centrler*)
   - **Kelip shıǵıw sebebi**: Qaraqalpaq tilinde *derek* sózi «bulaq, dáwir kózawayı, derek» (источник) mánisin ańlatadı. Russha «дата-центр» (data) sózin model maǵlıwmat penen emes, jasalma túrde *derek* penen almastırıp, «bulaq orayı» degen maǵanasız sóz payda etken. Informaciya hám maǵlıwmat saqlaw ornı qaraqalpaqsha **`maǵlıwmatlar orayı`** boladı.

3. **Dawıssızlar Assimilyaciyası hám Orfografiyalıq Qısqarıwlar**:
   - **Qátelik**: *ádeyir*
   - **Durıs**: **`ádeywir`** (sezilerli dárejede)
   - **Kelip shıǵıw sebebi**: Awızeki tilde `w` háribi jutılıp ketiwi múmkin, biraq ádebiy jazba tilde vokal-labial `w` háribi qatań saqlanıwı shárt.

4. **Analitikalıq Sóz Birikpeleri (Shama menen)**:
   - **Qátelik**: *shamamen*
   - **Durıs**: **`shama menen`**
   - **Kelip shıǵıw sebebi**: Qaraqalpaq tilinde shamalaw mánisi kómekshi sóz arqalı analitikalıq jol menen bildiriledi: sózlik quramında `shama` hám `menen` sózleri bólek jazıladı.

5. **Qazaqsha Sózlerdiń Qaraqalpaq Tekstine Kirip Ketiwi (Qazaqizmler)**:
   - **Qátelik**: *shıntlap* ➔ **`shın mánisinde / shınında da`** (qazaqsha: *шындап*)
   - **Qátelik**: *topılıs* ➔ **`qurallı hújim`** (qazaqsha: *топылыс*)
   - **Qátelik**: *jasawshı / jasawshıları* ➔ **`turǵın / turǵınları`** (qazaqsha: *тұрғындар*, *жасаушылар*)
   - **Qátelik**: *alımlar* ➔ **`ilimpazlar`** (qazaqsha: *ғалымдар*)
   - **Kelip shıǵıw sebebi**: Qaraqalpaq hám qazaq tilleri qıpshaq toparına kirgenligi sebepli, internet korpusında qazaq tilindegi adabiy emes dialektal formalar qaraqalpaqsha dep qabıl etiledi. Biraq qaraqalpaq ádebiy tilinde olardıń óz qat'iy normativ ekvivalentleri bar.

6. **So'zme-so'z Awırmalıq Kalkalar (Idiyomatik buzulıwlar)**:
   - **Qátelik**: *jas basqan adamlar* ➔ **`kekseler / jas úlkenler`** (russha «пожилые люди» sóziniń sózbe-sóz qátelik kalkası).
   - **Qátelik**: *shıń saatları* ➔ **`eń tıǵız saatlar`** (inglizshe «rush hour» / russha «часы пик» sózindegi «пик»ti tawdıń shıńı dep qáte kalkalaw).
   - **Qátelik**: *biytarap ońay emes arada* ➔ **`sońǵı waqıtlarda`** (quramalı kontekstti orınsız awdarıw).

7. **Post #294 hám #290-#293 Boyınsha Tereń Lingvistikalıq Hám Semantikalıq Analiz**:

   - **A. Semantikalıq Psevdo-Antonim («Jabıńqı» vs «Qaplama»)**:
     * **Qátelik**: *Jabıńqı* (Russha: «покрытие / гидрогелевое покрытие»).
     * **Durıs**: **`Qaplama`** (yamasa **`Gidrogel qaplaması`**).
     * **Kelip shıǵıw sebebi**: Rus tilindegi «покрытие» (jabıw, qaplaw) feyilinen jasalǵan atlıqtı awdarǵanda, model qaraqalpaq tilindegi *jabıńqı* sózin qollanǵan. Biraq qaraqalpaq tilinde *jabıńqı* sózi materiallıq qaplamanı EMES, psixologiyalıq jaǵdaydı yamasa hawa-rayın ańlatadı: «qabaǵı jabıńqı» (túnergen, keypi joq, depressiyalıq halat), «hawa jabıńqı» (bultlı). Medicinalıq hám texnikalıq obyektti qaplawshı qatlam qaraqalpaqsha tek **`qaplama`** dep ataladı.

   - **B. Tiri Toqıma vs Tınıq Toqıma («tınıq toqymalar»)**:
     * **Qátelik**: *tınıq toqymalar* (Russha: «живые ткани»).
     * **Durıs**: **`tiri toqımalar`**.
     * **Kelip shıǵıw sebebi**: Eki qátelik birikpesi: 1) Model «живой» sózin «тихий/чистый» dep adasıp *tınıq* (tınıq suw, tınıq hawa) dep qáte semantika bergen. 2) Qaraqalpaq latın imlosında `y` háribi rus tilindegi «ы» emes, «й» háribin ańlatadı. Sonlıqtan *toqymalar* sózi fonetikalıq hám orfografiyalıq tárepten qopal qátelik esaplanadı. Biologiyalıq organikalıq toqıma — **`tiri toqıma`** boladı.

   - **C. «Kúyik» sóziniń deformaciyası («kútik»)**:
     * **Qátelik**: *kútik* (Russha: «ожоги»).
     * **Durıs**: **`kúyik`** (kúyik jaraqatları).
     * **Kelip shıǵıw sebebi**: Qaraqalpaq tilindegi *kúyiw* feyilinen jasalǵan atlıq — *kúyik*. Mashina awdarmasında konsonantlar almashıp, tilde ulıwma bolmaǵan *kútik* degen jasalma sóz payda bolǵan.

   - **D. Tabıs Sepligi Sintaksisi (Grammatikalıq qátelik)**:
     * **Qátelik**: *jaraqatlarınıń ... jabatuǵın*
     * **Durıs**: **`jaraqatlardı ... jabatuǵın`**
     * **Kelip shıǵıw sebebi**: Sintaktikalıq basqarıw qáteligi. `Jabatuǵın` keltirindi feyili (participle) ótimli feyil bolǵanlıqtan, ózinen aldınǵı tolıqlawıshtı Ilik sepliginde (`-nıń`) emes, Tabıs sepliginde (`-dı / -ti / -nı`) talap etedi. Ilik sepligi qoyılǵanda sóz dizbegi iyelik mánisine aylanıp, sintaksislik baylanıs úziledi.

   - **E. Xalıqaralıq terminlerde 'k' hám 'q'**:
     * **Qátelik**: *kletqalardı*
     * **Durıs**: **`kletkalardı`**
     * **Kelip shıǵıw sebebi**: Qaraqalpaq tilinde xalıqaralıq (rus hám grek-latın) ózlespe sózlerde `k` háribi jińishke de, juwan da buwınlarda óz qálpinde `k` bolıp jazıladı (*kletka, traktor, leksika, texnika*). Olardı qatań `q` menen jazıw imlo qaǵıydalarına ziyan keltiredi.

   - **F. Restriktivlik Kvantifikatorı («Barlıǵı» vs «Barı-joǵı»)**:

     * **Durıs**: **`barı-joǵı tórt saat`**.
     * **Kelip shıǵıw sebebi**: *Barlıǵı* sózi qaraqalpaqsha «hámmesi, barlıq sani» (total, sum) degen mánisti ańlatadı. Sheklew, azlıq («всего лишь») mánisin beriw ushın bolsa qaraqalpaq tilinde tek **`barı-joǵı`** birikpesi qollanıladı.

   - **G. Singarmonizm hám Fonetikalıq Assimilyaciya (Post #290)**:
     * **Qátelik**: *ilimlerinin' kandidati* ➔ **`ilimleriniń kandidatı`** (`kandidat` sózi juwan buwınlı bolǵanlıqtan, ilik/tartım jalǵawı da juwan `-ı` bolıwı shárt; `n'` háribi 2016-jılǵı alfavit boyınsha `ń`ǵa almastırıladı).

     * **Qátelik**: *taldap shıǵıw* ➔ **`tallap shıǵıw`** (qaraqalpaq tilindegi `ld` ➔ `ll` assimilyaciyası: qaraqalpaqsha *tallaw* boladı, qazaqsha *taldaw* emes).
     * **Qátelik**: *Tarix* ➔ **`Tariyx`** (qaraqalpaq ádebiy tilinde `iy` diftongı menen jazıladı).

9. **#294-#386 Postlar Aralıǵındaǵı Lingvistikalıq, Semantikalıq hám Sintaktikalıq Qátelikler Taliqlaması**:

   - **A. Geologiyalıq hám Tábiyiy Terminlerdiń Buzılıwı («Mars tuqımı» vs «Mars jınısı» - Post #380)**:
     * **Qátelik**: *mars tuqımı*
     * **Durıs**: **`mars jınısı`** (yamasa *taw jınısı*)
     * **Kelip shıǵıw sebebi**: Rus tilindegi «марсианская порода» (geologiyalıq jınıs, mineral qatlam) sózin model qaraqalpaq tilindegi *tuqım* (mal tuqımı, násil, egin tuqımı) sózi menen qáte kalkalaǵan. Tas yamasa planetar qabıq hesh qashan «tuqım» bolmaydı. Geologiyada qaraqalpaq ádebiy tilinde tek **`jınıs`** (*taw jınısları*) dep ataladı.

   - **B. Obyekt hám Harakat Kálkaları («Kólem taraw», «Ullı milletlik» - Post #386)**:
     * **Qátelik**: *kólem taraw boyınsha*, *Ullı milletlik «Yashil makon»*
     * **Durıs**: **`kóklemzarlastırıw boyınsha`**, **`Ulıwma milliy «Jasıl makan» joybarı`**
     * **Kelip shıǵıw sebebi**: Rus tilindegi «по озеленению» sózin mashina *kólem taraw* dep maǵanasız awdarǵan. Qaraqalpaqsha durıs ekvivalent — **`kóklemzarlastırıw`** (yamasa *kóklandırıw*). Sonday-aq, «Общенациональный» (Umummilliy) termini qaraqalpaqsha **`Ulıwma milliy`** boladı, *«Ullı milletlik»* emes. «Yashil» sózi bolsa qaraqalpaqsha **`Jasıl`** dep jazılıwı shárt.

   - **C. Masdar (Infinitive) Jalǵawı: «-egiw» vs «-eguw» (Post #386)**:
     * **Qátelik**: *terek eguw*
     * **Durıs**: **`terek egiw`**
     * **Kelip shıǵıw sebebi**: Qaraqalpaq tilinde feyildiń masdar (infinitive) forması qatań túrde **`-ıw / -iw`** boladı (*egiw, islew, biliw, toltırıw*). Ózbek tilindegi *-ish / -moq* yamasa dialektal *-uw* forması qaraqalpaq tiline kire almaydı.

   - **D. Dawıssızlar Qatańlasıwı hám Dáslepki Singarmonizm («Meteorittiń», «GFR-de» - Post #380, #384)**:
     * **Qátelik**: *Meteorittıń*, *GFRde*
     * **Durıs**: **`Meteorittiń`**, **`GFR-de`**
     * **Kelip shıǵıw sebebi**: *Meteorit* sóziniń sońǵı buwınında jińishke `i` dawıslısı bar. Singarmonizm qaǵıydası boyınsha ilik sepligi juwan `-tıń` emes, jińishke **`-tiń`** bolıwı shárt. Qısqartılǵan atamalarǵa (abbreviatura) seplik jalǵawı defis (`-`) arqalı jalǵanadı: **`GFR-de`**, **`AQSh-ta`**.

   - **E. Leksikalıq Ózbekizmlerdiń Tazalanıwı («tibbiyotta», «tezlestirip» - Post #372)**:

     * **Kelip shıǵıw sebebi**: Ruscha «отмывание денег» (money laundering) sózbe-sóz *juwıw* (suw menen juwıw) emes, qaraqalpaq nızamshılıǵı hám yuridikalıq terminologiyasında rásmiy túrde **`aqsha jıllaw`** (nızamsız dáramatlardı legallastırıw) dep belgilengen.
